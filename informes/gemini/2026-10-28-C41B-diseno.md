 * Propuestas de organización y visualización:
   * (a) Vista comparativa país × tema: Utiliza una matriz de datos (Data Grid). Fija la primera columna (Países) y la primera fila (Temas: Custodia, ETF, Fiscalidad). En lugar de volcar texto en las celdas, usa "chips" semánticos (Verde: Legal, Ámbar: Restringido, Rojo: Prohibido). Al pasar el ratón (hover), despliega un tooltip nativo con la explicación breve, la fecha de actualización y la fuente contrastada.
   * (b) Línea de tiempo por capas: Emplea un modelo de diagrama de Gantt o carriles de edición. El eje X es el tiempo; el eje Y son las capas (Regulación, Deuda, Energía). Coloca únicamente nodos visuales (círculos o rombos) en las intersecciones. Al hacer clic en un nodo, abre un panel lateral fijo que muestre las perspectivas contrastadas (optimista vs. cautelosa) y los enlaces a las fuentes originales, manteniendo el lienzo principal limpio.
   * (c) Noticias con caducidad: Implementa un carril inferior o lateral tipo "Bandeja de entrada". Codifica las noticias por color según su tiempo de vida (Rojo: 24h, Naranja: 7 días, Gris: 30 días). Las noticias deben desaparecer de la vista principal automáticamente al expirar, trasladándose a un archivo histórico y dejando solo los eventos de impacto sistémico permanente en la línea de tiempo.
   * (d) Marcado de certeza: Inserta un icono superpuesto en cada celda, noticia o nodo. Utiliza un escudo sólido verde para datos de fuente primaria (ej. actas de bancos centrales, SEC), un círculo rayado amarillo para informes de prensa o estimaciones, y un triángulo rojo de advertencia para rumores, declaraciones emocionales o información con posible sesgo narrativo.
 * Estructura de datos (JSON) para actualizaciones rápidas e IA:
   No anides los datos; utiliza una arquitectura relacional plana. Esto permite que la API de un LLM solo lea el archivo que necesita, reduciendo drásticamente el consumo de tokens y el coste.
   * countries.json: Diccionario estático de países. {"id": "ES", "name": "España", "region": "EU"}
   * topics.json: Diccionario estático de categorías. {"id": "tax", "name": "Fiscalidad"}
   * matrix.json: Tabla de uniones transaccional. [{"country_id": "ES", "topic_id": "tax", "status": "26%", "certainty": "primary", "source_url": "...", "date": "2026-10-28", "bias_flag": null}]
   * timeline.json: Eventos puros. [{"id": "ev_1", "date": "2026-10-28", "layer": "regulation", "summary": "Aprobación MiCA", "perspectives": ["Bullish: ...", "Bearish: ..."], "certainty": "primary"}]
   * news.json: [{"id": "n_1", "ttl_days": 7, "timestamp": 1793129420, "headline": "...", "bias_flag": "Lenguaje emocional detectado"}]
 * Mejoras ordenadas por ratio Utilidad/Esfuerzo:
   * Separación Front/Back: Extraer todos los datos del HTML a los archivos JSON propuestos, usando un script de JavaScript ligero (fetch()) para pintar la tabla al cargar. (Utilidad altísima / Esfuerzo bajo).
   * Tooltips de metadatos: Ocultar las URLs, fechas y notas de advertencia dentro de atributos title o tooltips de CSS, limpiando instantáneamente la densidad visual de las celdas. (Utilidad alta / Esfuerzo bajo).
   * Script de purga local: Añadir una función de JavaScript en el navegador que compare el timestamp y el ttl_days del JSON de noticias con la fecha del sistema, ocultando las caducadas al renderizar. (Utilidad alta / Esfuerzo bajo).
   * Filtros cruzados globales: Un desplegable superior que permita seleccionar un país y filtre automáticamente la matriz, la línea de tiempo y las noticias a la vez. (Utilidad alta / Esfuerzo medio).
   * Selector de densidad (Toggle): Un botón para alternar entre "Vista Semáforo" (solo colores y símbolos) y "Vista Datos" (texto, porcentajes y cifras numéricas). (Utilidad media / Esfuerzo medio).
   * Campos de sesgo y perspectivas en el esquema: Añadir los campos bias_flag y perspectives al JSON para forzar el hábito de registrar información multidimensional. (Utilidad media / Esfuerzo medio).
   * Carriles colapsables (Timeline): Añadir la funcionalidad de ocultar o minimizar capas temáticas enteras (ej. apagar "CBDC") para focalizar la investigación. (Utilidad alta / Esfuerzo alto).
   * Pipeline de actualización por LLM: Escribir un pequeño script en Python que lea URLs de noticias, extraiga la información, contraste perspectivas, asigne la certeza y genere automáticamente las nuevas entradas para los JSON, dejándolas listas para tu validación manual. (Utilidad altísima / Esfuerzo alto).
